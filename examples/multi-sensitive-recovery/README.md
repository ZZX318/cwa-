# 多敏感区覆盖恢复对照

本目录由 `python -B recovery_experiment.py` 生成三个数值案例：原单边敏感区、行距4 m且株距3 m的错位双敏感区、保护范围有重叠的双敏感区。布局均为合成数据，不等于真实果园或随机重复试验。

每组比较原相位、整体相位候选、保持原相位的局部边带恢复。保护范围、喷幅、作业高度、风和CAW默认设置相同；额外时间上限60 s。每条补喷段使用完整2 m喷幅，转场关喷，全部计划通过最终检查。

## 结果

0.1 m网格，面积单位m²、时间单位s。

| 案例 | 原相位 漏喷 / 时间 | 整体平移 漏喷 / 时间 | 局部边带 漏喷 / 时间 |
|---|---|---|---|
| 单边敏感区 | 4.00 / 85.96 | 0.00 / 121.23 | 0.00 / 98.61 |
| 密植错位双敏感区 | 21.54 / 71.83 | 15.40 / 74.67 | 0.00 / 96.39 |
| 密植重叠双敏感区 | 17.23 / 74.48 | 10.93 / 74.94 | 0.00 / 93.04 |

所有方案足迹违规记录为0。同一案例、同一分辨率下，受限冠层与可喷冠层面积保持不变。

局部边带不是全面占优：错位双敏感区的重复覆盖从3.00增至14.68 m²·次，估算喷量由40.59增至54.99模型量；整体平移没有新增重复覆盖，但仍剩15.40 m²漏喷。必须同时展示这些代价。

## 栅格复核

最终各方案使用0.05 m网格重新评价，未重新选择方案。单边原相位漏喷3.875 m²；错位双敏感区原相位与整体平移分别21.2425和15.2000 m²；重叠双敏感区分别16.9575和10.7625 m²。三个局部方案均未检出剩余漏喷。两档检查不能证明任意细网格收敛或连续面积严格为零；缓冲边缘仍存在数值安全间隔。

## 文件和操作

- `*.scene.json`：原始目标、障碍及保护来源，可在01面板加载。
- `*.comparison.json`：三种方法的完整计划、候选记录、失败原因、预算、面积与时间；每个方案还含0.05 m复核指标。
- `summary.csv`：三案例九行汇总。

在02点击“加载多敏感区密植样例”，在03选择0.1 m，再在02点击“比较整体平移与局部边带”。选择方案后点“应用并回放”，再去03查看最终覆盖。02“保存计划”会保存真正的补喷段；直接重新生成普通CAW航线不会自动保留补喷段。

场景改动使旧方案不再可应用。比较结果可以保存为JSON；先保存比较再应用，以免应用后的相位改变使输入签名失效。若要以当前规划为新起点，重新运行比较。

## 方法范围

最多200个目标，沿用相位入口最多16个候选；局部边界中心线最多32种，每轮评估前4个几何评分候选、最多补4段。采用有限贪心，不能称全局最优。仍为固定Y、固定喷幅、即时开关和保守矩形约束，未实现转向喷头、自动航向或真实漂移。时间及喷量为代理模型。

本组结果支持“局部恢复是必须纳入的竞争方案”，不支持“局部边带普遍优于相位”或新的算法创新结论。旧论文的滞后、盲预测和B与S_h结果未在本实验中重跑，不能混为一批。
